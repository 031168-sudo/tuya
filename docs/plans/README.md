# Планы дома — материалы и состояние работы

Отдельная задача: в приложении «Мой дом» сделать экран **«План дома»** — два этажа, комнаты закрашены
по температуре, на комнатах значки устройств (термостаты, конвекторы, датчики) и признак «греет / не греет».

## Исходники (от хозяина дома)

| Файл | Что это |
|---|---|
| `sources/floor1-source.jpg` | Чертёж 1-го этажа. **Красным** от руки дорисованы стены, которых нет на чертеже |
| `sources/floor2-source.jpg` | Чертёж 2-го этажа (то же — красные линии = дополнительные стены) |

## Что уже сделано

Лежит в приложении: `app/src/main/assets/plans/`

| Файл | Что это |
|---|---|
| `house.json` | Геометрия обоих этажей в миллиметрах: комнаты (прямоугольники, площадь), стены `[x1,y1,x2,y2,толщина]`, двери, окна, крыльцо/терраса |
| `floor1.svg`, `floor2.svg` | Красивые картинки этажей, собраны из `house.json` |
| `gen_plans.py.txt` | Скрипт Python, который генерирует `house.json` и SVG (переименован в .txt, чтобы не попадал в сборку как код) |

Система координат: ось Y вниз, мм. Оси чертежа:
- по горизонтали 1…5 = 0 / 1500 / 4000 / 6000 / 9000;
- по вертикали Д…А = 0 / 6000 / 7765 / 9500 / 11500.

Наружная стена 350 мм, перегородка 150 мм.

## Что не сделано / открытые вопросы

1. **Названия комнат.** Сейчас на 1-м этаже «Комната 1…5» и «Тамбур». Нужно, чтобы хозяин назвал комнаты
   (гостиная, спальня, коридор, ванная, летняя кухня…) — по ним комната свяжется с зонами отопления.
2. **Проверить стены**, дорисованные по красным линиям: правильно ли они поставлены.
3. **Экран «План дома»** в приложении (Jetpack Compose): отрисовать этаж по `house.json`, закрасить комнаты
   по текущей температуре, показать устройства и «греет / не греет», нажатие на комнату — график температуры.
4. Привязка «комната ↔ зона отопления / устройства» — хранить в настройках приложения.

# Перенос «Моего дома» в новый OpenCode

Проект полностью переносится через GitHub. Для работы нужен только доступ
к репозиторию `031168-sudo/tuya`.

**Новый OpenCode работает только с GitHub, как и раньше.** Никакие файлы
вне репозитория не нужны: исходники, история, ключ подписи, настройки
сборки и инструкции уже в GitHub. Сборка и тесты выполняются в GitHub
Actions, готовый APK публикуется в GitHub Releases.

## Что переносится

- Исходный код Android-приложения (Kotlin + Jetpack Compose).
- История Git и ветка `main`.
- Gradle wrapper и настройки проекта.
- `app/debug.keystore` — общий ключ подписи. Он уже в репозитории и должен
  остаться тем же, иначе новые APK не установятся поверх старых.
- GitHub Actions: `.github/workflows/build.yml`.
- Готовый APK последней сборки — в GitHub Releases.

## Как продолжить работу

1. Клонировать репозиторий `031168-sudo/tuya`.
2. Работать в ветке `main` или в отдельной ветке от `main`.
3. Изменения отправлять push в GitHub.
4. Сборку и unit-тесты выполняет GitHub Actions при push в `main`.
5. Готовый APK брать в GitHub → **Releases** (`MoyDom-<номер>.apk`).

Ручной запуск сборки: GitHub → **Actions** → **Build APK** →
**Run workflow**. Сборка выполняется в GitHub Actions.

## Подпись и обновления

Все сборки подписываются одним ключом `app/debug.keystore` с параметрами
из `app/build.gradle.kts`. Не заменять этот файл и не менять пароль/alias:
иначе Android не установит новый APK как обновление.

`versionCode` автоматически равен номеру запуска GitHub Actions. Поэтому
APK из Releases всегда устанавливается поверх предыдущего.

## Что не хранится в Git

- Access ID / Access Secret Tuya.
- Логины, пароли и сессии Rubetek и Xiaomi.
- PIN и пароль чтения НАРТИС.
- Данные, которые приложение хранит на телефоне.

Эти данные вводятся на телефоне и остаются в его защищённом хранилище.
В репозиторий их добавлять нельзя.

## Проверка после переноса

1. В GitHub открыть последний успешный запуск **Build APK**.
2. Убедиться, что в **Releases** есть APK `MoyDom-171.apk` или новее.
3. Скачать APK из Releases и установить на телефон.
4. Убедиться, что приложение открывается и видит прежние настройки.

## Важно

Дальше все изменения, проверки и сборки ведутся **в GitHub**, как и раньше.
Источник истины — репозиторий `031168-sudo/tuya`.

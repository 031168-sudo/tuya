# Tuya Control

Android-приложение (Kotlin + Jetpack Compose) для просмотра и управления устройствами из аккаунта Tuya Smart / Smart Life через Tuya Cloud OpenAPI.

## Что умеет сейчас
- Список всех устройств привязанного аккаунта, статус «онлайн / не в сети».
- Показания: мощность, напряжение, ток, энергия, температура, влажность и т.д. (с учётом множителей из спецификации устройства).
- Включение и выключение (`switch`, `switch_1`…), изменение уставок (например, `temp_set` у термостата).
- Обновление свайпом вниз и автоматически раз в минуту, пока приложение открыто.
- **Энергия и расходы** (кнопка «₽» или «История потребления и расходы» на карточке счётчика):
  потребление и стоимость за день / неделю / месяц / год, график, разбивка по устройствам и дням.
  История берётся из сервиса Tuya **Data Statistics** за всё время с даты активации; если сервис
  не подключён — копится из журнала устройства (облако хранит 7 дней).
- **Тарифы**: период действия (с/по) и до трёх зон по времени суток (Т1–Т3), у каждой цена за кВт·ч
  и 1–2 интервала часов (например, ночь 23–7; пик 7–10 и 17–21). Общие или для конкретного счётчика.
  Расход каждого часа умножается на цену зоны, действовавшей в этот час и день. Почасовые данные берутся
  из `statistics/hours`; для дней, где их нет, расход разносится по среднему профилю счётчика (помечено «≈»).
- Учитываются только счётчики «智美WiFi开关电表».
- Экран «Логи» (значок ⓘ): все запросы к Tuya и ответы, ключи в логе скрыты.

## Установка
1. Откройте на телефоне **Releases → последняя сборка** и скачайте `MoyDom-N.apk`.
2. Разрешите установку из этого источника и установите.
3. При первом запуске введите **Access ID** и **Access Secret** (platform.tuya.com → Cloud → проект → Overview) и выберите дата-центр **Central Europe**.

Ключи хранятся только на телефоне (EncryptedSharedPreferences), в репозитории их нет.
Все сборки подписаны одним debug-ключом (`app/debug.keystore`), поэтому новые версии ставятся поверх старых без потери настроек.

## Сборка
Каждый push в `main` собирает APK в GitHub Actions и публикует его в Releases.
Локально: `./gradlew assembleDebug`.

## Устройство проекта
- `cloud/TuyaCloudClient.kt` — подпись HMAC-SHA256, токен, устройства, статус, спецификация, команды.
- `data/CredentialsStore.kt` — зашифрованное хранение ключей.
- `MainViewModel.kt` — состояние, обновление, отправка команд.
- `ui/` — экраны настройки, устройств и логов.

## Планы
- Локальный режим по LAN: поиск устройств по UDP (6666/6667), протокол Tuya 3.3/3.4/3.5 с `local_key` из облака, автоматическое переключение облако ↔ локально.
- История показаний.

## Важно
Бесплатный тариф IoT Core в консоли Tuya выдаётся как пробный и требует периодического продления. Если он истечёт, приложение покажет ошибку доступа.

## Категории и иконки
Вкладка «Категории»: плитки с названием, иконкой и пастельным цветом; нажатие показывает устройства категории.
Иконка и категория устройства назначаются кнопкой ⋮ на карточке; карточки окрашиваются в цвет категории.
Иконки — выборка из [Google Material Icons](https://github.com/google/material-design-icons) (Apache License 2.0),
встроенная как данные путей SVG (`ui/DeviceIcons.kt`).
